# CRITICAL: Platform uniqueness (AdSense + Google)

## Non‑negotiable
1. **Blogger content is AdSense-critical.** Topics, titles, body text, and **hero images** used on Blogger must NOT be reused on Medium, HubSpot, WordPress, or FreeDailyPro.com.
2. **No “same topic, rewritten”** across Blogger ↔ Medium. Different audience angle is NOT enough — **topic must be different**.
3. **No shared hero images** across platforms. Every platform gets its own generated + branded image file.
4. HubSpot / WordPress / Medium may share *broad* product themes only if title, outline, examples, and image are all unique — **never** when Blogger already owns that theme for the week.
5. When in doubt: **Blogger wins exclusivity** for that theme.

## Week planning checklist
- [ ] List Blogger 7 topics first
- [ ] Medium 7 topics = zero overlap with Blogger list
- [ ] Generate Medium images only after Medium topics locked
- [ ] Never copy `blogger/images/*` into `medium/images/*`

## Violation fix
If a Medium post reused a Blogger theme or image: delete or replace Medium version with a new exclusive topic + new image before publish.
