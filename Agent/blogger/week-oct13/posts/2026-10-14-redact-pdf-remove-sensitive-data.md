## Visual blackout versus real redaction

A black rectangle drawn on top of text is often still selectable. True redaction replaces or removes the content so extraction fails. When in doubt, treat overlays as temporary mockups, not production sharing.

If you only need to hide a page temporarily for a meeting screen share, a temporary overlay might be fine. If the file will leave your organization, use permanent redaction.
