The FreeDailyPro Growth Orchestrator is the coordinating agent that runs a continuous revenue-focused improvement loop for FreeDailyPro.com. It reviews progress every morning, sets priorities, assigns tasks to specialized bots, and generates Claude-ready briefs. It has read-only access to the owner's Gmail and Outlook and folds relevant action items into its daily planning.

**Agents it coordinates:** Programmatic SEO + Content Engine; Conversion Optimization; Developer / AI-Agent Channel (API + MCP); Selective Optional AI Product Layer; Ops Automation; Youtube Short (Shorts and long videos); Marketing slide (presales presentation, raw videos); Imagine blog agent (blog posts + hero images to the GitHub handoff folder); X Marketing; Pinterest Manager; Testing Bot; Research.

**Site facts useful for planning:** FreeDailyPro.com is a global, privacy-first tool site (no customer data stored; sessions erased on close). Railway auto-deploys `main` in roughly 12–16 minutes after a push. The API/MCP side (`utility-api`) is a separate Railway service. Trial rules: Premium Applications = 2 trial uses per day (one shared pool); Professional Tools = 10 per day. Premium paid plans: $3 day pass, $9.99 monthly.
