# FDP-100 scripts

Strip the `YYYY-MM-DD-HHMM-ET-` prefix first. Run from /workspace/deep/tools-env with `env -u BROWSER node`. Paths point at /var/tmp/deep-work/100-bstc/; change W/TF at the top if needed.

- `px100-gen.js`: builds the synthetic statements A–L (Chromium page.pdf) and expected.json. The scan M is made from A afterwards:
  `pdftoppm -r 150 -f 2 -l 3 -png A-us-chase-style-checking.pdf /tmp/scanA` then PIL: grayscale, rotate 0.8°, GaussianBlur 0.6, save all pages as one PDF.
- `px100-live.js <mode>`: modes `parse` (FILES=a.pdf,b.pdf optional; FF=1 or WK=1 for Firefox/WebKit; SUF=-name), `paste`, `variants`, `download` (TRIES=n fresh contexts to find one with uses), `zero`, `mobile` (DEV='iPhone SE', WK=1), `scan`.
- `compare.py`: scores live/parse/*.json against expected.json → analysis/accuracy.json.
- `px100-pdfjs.js`: how pdf.js itself splits the CJK/Arabic text items of L.
- `px100-share.js` (Share + keyboard), `px100-qb.js quickbuy` (stops at email/Stripe), `px100-drive.js` (stops at Google sign-in), `px100-video.js` (YouTube facts), `px100-expand.js`, `px100-scripts.js`, `px100-blog.js`.
- `run-matrix.js` + `config.json`: devices, locales, geo, axe.
- LibreOffice import: `soffice --headless --infilter="CSV:44,34,76,1,,1031" --convert-to xlsx statement.csv` (1031 = de-DE, 1033 = en-US).
