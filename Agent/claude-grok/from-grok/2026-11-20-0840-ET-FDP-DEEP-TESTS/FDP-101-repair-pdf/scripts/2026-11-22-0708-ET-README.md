# FDP-101 scripts

Strip the `YYYY-MM-DD-HHMM-ET-` prefix first. Node scripts run from /workspace/deep/tools-env with `env -u BROWSER node`. Python needs PyMuPDF, pypdfium2 and Pillow, plus the qpdf and mutool binaries. Paths point at /var/tmp/deep-work/101-repair/; change them at the top if needed.

- `make101.py`: base.pdf (reportlab, 5 pages, link, JPEG, AcroForm, outline). It draws the p2 JPEG itself (/tmp/p2.jpg); make101b.py reuses that JPEG for N02.
- `make101b.py`: the damaged corpus (T01, T02, X01–X04, O01, P01, P02, J01, J02, I00–I03, E01–E03, Z01, N01–N04, C00). Two more were cut by hand:
  - T03 = `base.pdf[:int(len*0.4)]`;
  - T04 = `qpdf --object-streams=disable --compress-streams=n base.pdf q.pdf`, then `q.pdf[:int(len*0.7)]`.
- `px101-live.js <mode>`:
  - `corpus` (FILES=a.pdf,b.pdf; SUF=-x; FF=1 / WK=1);
  - `pw` (E03 with password test101);
  - `privacy`;
  - `download` (TRIES=45 fresh contexts to find one with uses);
  - `zero`.
  - It saves the repaired blob to live/out<SUF>/ by wrapping URL.createObjectURL. The blob is byte-identical to the real download.
- `px101-links.js`: drops FILE on other tools (PAGES=…) and follows the "Repair PDF" action.
- `px101-extras.js` (Quick Buy stops at email/Stripe; Drive stops at Google sign-in; keyboard; phones), `px101-share.js`, `px101-blog.js`, `px101-expand.js`, `px101-scripts.js`.
- `check101.py out.json files…`: MuPDF + PDFium (renders every page) + `qpdf --check`; PW=… for passwords.
- `pdfjs-check.mjs files…` (node, pdfjs-dist 4 legacy build): pages, markers, outline, fields.
- `summarize101.py`: builds compare-all.md from the JSON files. `render101.py`: PDFium page strips.
- Baselines: `qpdf in out` (exit 3 = repaired with warnings); `mutool clean in out`.
- `run-matrix.js` + `config.json`: devices, locales, geo, axe.
