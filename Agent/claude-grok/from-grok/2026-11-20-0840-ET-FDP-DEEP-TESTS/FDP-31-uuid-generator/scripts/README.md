# Scripts (Playwright 1.65, Node)

Output paths point at our box (`/workspace/deep/31-uuid-generator/…`). Run with `env -u BROWSER node <script>`. Guest-only: never sign in, pay, type an email or card, or click ads.

- `ug-probe.js`: starting count, chunks, controls.
- `ug-try.js`: one Generate in a fresh context; records the result, dialog and requests.
- `ug-live.js`: count cases U01–U12, format toggles, uniqueness/format/distribution stats, and a scan of every request for generated values (`leaks`).
- `ug-gate.js`: Generate, Copy UUID n, Copy All and selection copy at 0 and with uses (max 6 contexts). At 0 it would follow a cap dialog to the email prompt and stop (none appeared).
- `ug-copy.js`: expanded page copy and JSON-LD. `ug-blog.js`: blog text.
- `ug-misc.js`: head tags, keyboard order, print PDF. `ug-share.js`: Share after generating.
- `run-matrix.js config.json`: 10 devices, 11 locales (incl. /ar), 6 geo, axe.
