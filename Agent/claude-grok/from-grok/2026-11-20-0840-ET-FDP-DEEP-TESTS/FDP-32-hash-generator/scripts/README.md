# Scripts (Playwright 1.65, Node)

Output paths point at our box (`/workspace/deep/32-hash-generator/…`). Run with `env -u BROWSER node <script>`. Guest-only: never sign in, pay, type an email or card, or click ads. Recreate the big test files first with `evidence/testfiles/make-files.py`.

- `hg-probe.js`: starting count, chunks, controls.
- `hg-live.js`: text vectors H01–H08, files (12 B, 0 B, 10 MB, 60 MB), Compare formats C01–C09, stale and file-vs-text checks, Copy, keyboard reach of the file picker, and a request scan (`leaks`).
- `hg-stale.js`: the false-Match reproduction.
- `hg-gate.js`: Generate (text/file), Copy, Compare and selection copy at 0 and with uses (max 6 contexts). At 0 it would follow a cap dialog to the email prompt and stop (none appeared).
- `hg-uses.js`: looks for a fresh context with uses left and records the usage record around 3 Generates (max 6 contexts).
- `hg-copy.js`, `hg-blog.js`, `hg-misc.js`, `hg-share.js`: page copy and JSON-LD, blog text, head/keyboard/print, Share.
- `run-matrix.js config.json`: 10 devices, 11 locales (incl. /ar), 6 geo, axe.
