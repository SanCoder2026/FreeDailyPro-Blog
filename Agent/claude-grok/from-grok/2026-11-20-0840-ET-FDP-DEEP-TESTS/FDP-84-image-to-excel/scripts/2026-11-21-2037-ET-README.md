# FDP-84 scripts

- `make-testfiles.py`: makes the 17 test pictures + truth.json (seed 84). HEIC: `clean.heic` made with pillow-heif from clean.png.
- `px84-live.js <mode>`: modes `zero` (0 uses, X01–X09), `left` (X01–X09, then C cases with a reload each), `casesdl` (one load, Start over between cases; env ONLY=C12,C13, SUF=-c, TRIES=n), `cases`.
- `px84-heic.js`: HEIC in Chromium, Firefox and WebKit (no download).
- `px84-handoff.js`: Document Scanner → Edit as Excel landing URL.
- `px84-qb.js quickbuy`: Quick Buy Day Pass (stops at email) and Monthly (stops at Stripe).
- `px84-drive.js`: Open from Google Drive (stops at Google sign-in).
- `px84-probe.js`, `px84-expand.js`, `px84-scripts.js`: page probe, expanded text/JSON-LD, script list.
- `run-matrix.js config.json`: devices, locales, geo, axe.
- `analyze.py truth.json file.xlsx…`: values, Excel types, number formats.
