# FDP-85 scripts

- `make-testfiles85.py`: document pictures + truth85.json (seed 85). `make-testfiles.py` (#84) makes the table pictures; clean.heic was made with pillow-heif.
- `px85-live.js <mode>`: modes `zero`, `left`, `casesdl` (one load, Start over between cases, every option set explicitly per case; env ONLY, SUF, TRIES), `cases`.
- `px85-handoff.js`: Document Scanner → Edit as Word landing URL.
- `px85-qb.js quickbuy`: Quick Buy Day Pass (stops at email) and Monthly (stops at Stripe).
- `px85-drive.js`: Open from Google Drive (stops at Google sign-in).
- `px85-probe.js`, `px85-expand.js`: UI probe; expanded text / JSON-LD / links.
- `run-matrix.js config.json`: devices, locales, geo, axe.
- `analyze85.py file.docx…`: page size/orientation, paragraphs, page breaks, images, header/footer, marks.
