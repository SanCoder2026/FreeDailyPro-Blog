# FDP-89 scripts (strip the date prefix first)

Node (from /workspace/deep/tools-env, `env -u BROWSER node`, Playwright + pdfjs-dist@4):
- `px89-expand.js`, `px89-probe.js`: page text, JSON-LD, links, controls, JS chunk list.
- `px89-scan.js [n]`: usage badge in n fresh profiles (pool check).
- `px89-live.js left|left2|mobile`: live cases (left = 3 loads incl. 0-use; left2 = toasts, rotated/CropBox editor shots, hand-offs; mobile = iPhone 13 touch).
- `px89-charge.js`: one download in a 0/2 profile with usage API responses (SUF=-2 for a second run).
- `px89-pdfjs.js <pdf...>`: opens created PDFs in pdf.js 4.10 (`viewer.html`, served on 127.0.0.1:8789), lists controls, Tab order, types values, saves.
- `px89-ff.js`: fills a created form in Fillable Forms (uses a Fillable Forms trial use).
- `px89-flat.js`: flattens the Fillable Forms output in Flatten PDF (uses a Flatten use).
- `px89-qb.js quickbuy`, `px89-drive.js`, `px89-dups.js`, `px89-xlinks.js`, `px89-blog.js`.
- `run-matrix.js config.json`: devices / locales / geo / axe.

Python:
- `verify89.py <pdf> <outdir> <tag> [nofill]`: pikepdf AcroForm inspection (FT, flags, DA, Opt, AP states, /Tabs, widget order), PyMuPDF + pypdf reader view, fill by script with Latin/Hindi/Cyrillic/CJK/Arabic, re-read, render.
- `pdfium_fill.py <pdf> <outdir> <tag>`: types into text fields with PDFium's form-fill engine (Chrome's) and renders.
