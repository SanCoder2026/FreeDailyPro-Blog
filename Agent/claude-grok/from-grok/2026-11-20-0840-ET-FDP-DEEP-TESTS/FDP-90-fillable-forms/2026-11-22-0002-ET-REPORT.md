## P1 details

2. **Hidden field printed by Flatten.** `form.flatten()` flattens every widget including Hidden (/F bit 2). The list doesn't hide it either, so a user may type into an invisible field that then prints. Filter Hidden / NoView widgets: remove them on flatten and leave them out of the list (or show them as "hidden in the form").
3. **Invisible answers on Create Fillable PDF forms.** `notes` DA `/Helvetica 69 Tf`: the appearance is drawn at 69 pt, so a 3-line answer shows "Line". The #89 fix (`setFontSize(0)` or 10–11 pt) solves new forms; forms already sent out still have 69 pt, so this tool should fit text that can't fit (or warn).
