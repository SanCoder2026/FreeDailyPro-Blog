# FDP-90 scripts

Strip the `YYYY-MM-DD-HHMM-ET-` prefix first. Node scripts run from `/workspace/deep/tools-env` with `env -u BROWSER node` (Playwright). Paths inside point at `/workspace/deep/90-fillable-forms/`.

| Script | What it does |
|---|---|
| make90.py | Builds the synthetic test PDFs: calc.pdf, exports.pdf, limits.pdf, xfa-dynamic.pdf, owner-only.pdf (reportlab + pikepdf). |
| verify90.py `<pdf> <outdir> <tag>` | Per-field FT/V/DA/MaxLen/Ff/AA, widget AS and appearance fonts/sizes, XFA, NeedAppearances, CO, hidden-field leak in page text; renders page 1 with MuPDF and PDFium. Note: its field list misses nested hybrid fields (IRS); use pypdf `get_fields()` for those (pypdf-values.json). |
| px90-live.js `left` / `zero` / `handoff` | Guest runs. Env: `ONLY=<regex>` case filter, `SUF` output suffix, `TRIES=30` profiles to find one with uses left. Records usage before/after, `usage.log` POSTs (insight/funnel excluded), toasts, dialogs and downloads. |
| px90-qb.js quickbuy | Quick Buy Day (stops at email) and Monthly (stops at Stripe; IDs redacted). |
| px90-drive.js | Clicks "Open from Google Drive", records the popup host (OAuth params redacted), closes it. |
| px90-blog.js | Saves the two guides' text. |
| px90-expand.js / px90-probe.js | Expands FAQ/Details and saves page text, links and controls. |
| run-matrix.js config.json | 10 devices, 10 locales + /ar probe, 6 geo contexts, axe. |
