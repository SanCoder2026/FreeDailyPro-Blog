## Intent

Someone opening an online PDF editor wants to change a wrong value so that it looks native, mark up a document, add a logo, and tidy pages, then send a file the recipient can trust. Markup works well and lands exactly where placed. But edited text looks pasted on, keeps the old value underneath, and can break in Hindi. There are no page tools. Everything is burned in rather than saved as comments, and the help text contradicts the tool. The usage gate repeats the shared per-load issue.
