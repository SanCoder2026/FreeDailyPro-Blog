# Competitor baseline (read 2026-11-22 ET; vendor pages and two Nov 2026 comparisons)
- Sejda (https://www.sejda.com/pdf-editor): click existing text to edit; change size, font family, colour, bold/italic; keeps the original font where possible and asks for a replacement font when a character is missing. Free web tier 200 pages / 50 MB / 3 tasks per hour. Not on scans.
- iLovePDF (https://www.ilovepdf.com/blog/edit-pdf-text): "Select text to edit, move, or delete the existing content"; add text, images (resizable), shapes, freehand with colour and thickness.
- Smallpdf (https://smallpdf.com/edit-pdf): add text, images, shapes, highlights, sticky notes; Organize mode (rearrange, merge, extract, split) inside the editor; editing existing text is Pro (7-day trial).
- Comparisons: https://pdftextfix.com/compare/online-pdf-editors (Oct 12 2026), https://siliph.com/blog/best-free-online-pdf-editors-compared/ (Nov 3 2026).
