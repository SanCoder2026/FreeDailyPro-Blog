# FDP-96 scripts

Strip the `YYYY-MM-DD-HHMM-ET-` prefix first.

- `make96.py` (python3, PyMuPDF + pikepdf): builds testfiles/mixed.pdf, rotated.pdf, crop-offset.pdf. Other inputs come from #88/#91–#95 (make93.py, make94.py, form/heavy/large makers).
- `px96-live.js` (Playwright, from tools-env: `TRIES=40 env -u BROWSER node px96-live.js <mode>`): guest live runs. Modes: explore, core, nonlatin, err, batch, xtra, capload, atcap, cont, mobile (`DEV='iPhone 13'`, `WK=1` for WebKit), prevx (`FILES`, `POS`), nlprev. Env: `ONLY` (regex on case IDs), `SUF` (output suffix), `TRIES`, `NEED0`, `MAXUSED`. Paths at the top (`W`) point at /workspace/deep/96-add-page-numbers/.
- `verify96.py <orig> <out> <outdir> <tag> <position> '<expected|per|page>'`: text, visible position, upright, render diff (trial mark masked), links, fields, bookmarks, hidden pages, catalog keys, fonts/images added. Writes `<tag>.json` and per-page number crops.
- `rep96.js`: a local pdf-lib re-implementation of `pn()` (Latin path only) used to predict geometry while every guest profile was at 10/10. Reference only; every finding comes from live outputs.
- `t96.js`: probes the usage count across fresh contexts.
- `config.json`: matrix config (run-matrix.js from tools-env).
