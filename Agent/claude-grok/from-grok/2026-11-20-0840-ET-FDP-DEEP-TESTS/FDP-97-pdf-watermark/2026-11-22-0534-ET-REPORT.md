## Findings

**P1 #1 — One trial use covers every download in a page load (same as #95 P1 #3, #96 P1 #1).**
Core: 18 different watermarked files in one load → one usage POST, 0→1/10. nonlatin: 9 → 1; img: 3 → 1. In `xl` the shared count became 10/10 during the build and Download still delivered the 107 MB file without the cap dialog. A fresh load at 10/10 shows "Today's trial uses are done … Monthly for $4.99 … Day Pass for $1". Shared `gateAtDownload`; owner ruling: charging per page load is P1.

**P2 #2 — The watermark is trivially strippable, and the FAQ implies otherwise.**
The mark is a separate content stream per page (`/GS-n gs` + `/Helvetica-Bold-n Tf` or `/Image-n Do`), not an annotation, layer or artifact, so it is invisible to viewers' "remove watermark" UIs, but any script that drops that stream restores the original exactly. `strip97.py` (26 lines) did this on 5 outputs (doc, crop-offset ×2, toc-links, book; 48 pages) without the original: 0 px difference on every page; original links, fields and bookmarks still there (findings/strip-demo.md, verify/strip-check.json). The FAQ "Can I remove a watermark I added by mistake? Not with this tool — once a watermark is drawn onto the page content and saved, it's part of the document like any other page content" suggests removal is as hard as editing the text. To its credit, "When not to use" says "A watermark is a visible label, not protection … the file can still be edited", so this is wording plus a missing option, not a false security promise. Suggested: say honestly that a watermark deters but can be removed, and offer "Make it permanent" (Flatten/Rasterize handoff) for people who need that; optionally mark the stream as `/Artifact` (accessibility) or put it in an OCG so viewers recognise it. The trial badge is removable the same way: owner question Q2, not a bug.

**P2 #3 — Non-Latin watermarks become pictures.**
Cyrillic, CJK, Arabic, emoji and anything with `№` are drawn as one PNG of the whole label: not searchable, not read aloud, and the Latin part of a mixed label (`🔒 SECRET`, `Entwurf № 3`) becomes a picture too. Hindi is real FreeSans text (searchable) but not bold, so it looks lighter than other scripts. Suggested: embed a subset font per script (as done for Devanagari), keep Latin runs as Helvetica.

**P2 #4 — Tiled non-Latin text bloats files (one PNG per tile, no reuse).**
doc.pdf (6 pages) with tiled `机密`: 11 KB → 2.1 MB (91 images per page) vs 47.7 KB for tiled `COPY`. 300 pages: **2.87 MB → 107.4 MB, 126.8 s**, 27,300 images. Image logos are embedded once and reused, so the fix is simple: render the label PNG once and draw the same XObject for every tile/page. Latin tiling also adds one font dict per tile (300 pages: +24,795 objects, +1.1 MB); embed Helvetica-Bold once.

**P2 #5 — Limitations and "When not to use" contradict the tool.**
"Every page gets the stamp, with no page-range option, and it is drawn on top of the content rather than behind it" and "cannot mark only a chosen section": the tool has a Pages box, Skip the first page and a Layer option (all verified). Users who read the Limitations leave for another tool.

**P2 #6 — Locale pages and blog.** (a) de/ja: controls, hints, strapline, drop zone, title and meta are English. (b) /blog/pdf-watermark gives wrong defaults (#b3b3b3, 30 %) and sends readers to Split PDF for partial watermarking; no Layer mention.

**P2 #7 — The video shows an older, smaller tool.** See check 12. Re-record with the current UI (image logo, tiled, behind, ranges); drop "Free" / "5 free uses".

**P3 #8 — Image errors:** TIFF and unreadable images show only "Failed to add watermark"; the precise message ("TIFF is not supported yet. Convert it to JPG or PNG first") is only in the console, though the FAQ promises it.
**P3 #9 — Behind on scans/solid backgrounds:** the mark is invisible yet present and searchable (W10). The hint warns; detecting a full-page image/fill and suggesting "On top" would prevent silent failure.
**P3 #10 — Mixed sizes:** single-position text sized to the smallest page looks tiny on large pages; offer "size relative to each page".
**P3 #11 — Text layer:** tiled Latin adds 44 copies of the word per page to search/copy/screen readers; mark watermark text as `/Artifact`.
**P3 #12 — Badge crowding:** with Bottom Right or Tiled the trial badge sits next to/over the user's mark; consider moving the badge when the user chose bottom-right (badge itself intentional, see Q2).
**P3 #13 — SEO/a11y details:** FAQ duplicates (Tiled ×2, copying ×2, language ×2); meta 71 chars; VideoObject `uploadDate`/name differ from YouTube; OG image generic; axe `label-content-name-mismatch` (.right-2), `region`; ad label contrast on Pixel 7; iPhone SE +9 px (sitewide). Hindi wrongly gets the "drawn as a picture" note (P3, part of #3 fix).
