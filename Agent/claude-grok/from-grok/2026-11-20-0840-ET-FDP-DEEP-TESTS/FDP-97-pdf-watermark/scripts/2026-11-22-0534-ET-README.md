# FDP-97 scripts

Strip the `YYYY-MM-DD-HHMM-ET-` prefix first.

- `make97.py` (python3, PyMuPDF + Pillow): builds testfiles/scan.pdf and the logos (png, tall png, EXIF-6 jpg, webp, gif, svg, tiff, fake png). Other inputs come from #91–#96 makers.
- `px97-live.js` (Playwright, from tools-env: `TRIES=60 env -u BROWSER node px97-live.js <mode>`): guest live runs. Modes: explore, core, nonlatin, img, err, inputs, xl, batch, xtra, atcap, cont, mobile (`WK=1` for WebKit, needs `GIO_EXTRA_MODULES`). Env: `SUF`, `TRIES`. Paths at the top (`BASE`) point at /workspace/deep/97-pdf-watermark/.
- `px97-qb.js quickbuy`: Quick Buy Day Pass (stops at email) and Monthly (stops at Stripe, IDs redacted).
- `verify97.py <orig> <out> <outdir> <tag> '<json expect>'`: per page watermark stream vs badge stream, layer, opacity, artifact marking, text/image ops, search hits, render-diff position/margins/angle, strip diff, links, fields, bookmarks, hidden pages, catalog keys, boxes.
- `strip97.py <in> <out>`: removes the watermark and trial-badge content streams without the original (shows P2 #2).
- `config.json`: matrix config (run-matrix.js from tools-env).
