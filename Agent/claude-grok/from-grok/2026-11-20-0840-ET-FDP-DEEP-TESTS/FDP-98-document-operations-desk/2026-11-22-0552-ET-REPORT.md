## Findings (verified as a guest)

**P2 #1: Nothing shows the product before the trial.** For $29.99/month there is no video, screenshot, sample `packet.zip`/`audit-log.csv`/manifest or demo packet. "What you get before you pay" lists files but offers none. Suggested: a 60–90 s video, a screenshot of the run with the audit table, and a downloadable sample packet (made-up documents) showing the manifest and checksums.

**P2 #2: Page claims that the product (and its own guide) contradict.**
- "Recipes that chain the steps… in the order you choose". The guide says "they run in the order shown", and the code sorts ticked steps into scan → OCR → organize → redact → number → compress → sign.
- "Try one step first: Merge PDF: combine a few PDFs" presents merging as a step of this job. The desk has no merge step; the packet is a ZIP of separate PDFs.
- Limitations: "Signing places a drawn or typed signature image". The code draws a typed name in Helvetica-Oblique on a line on the last page; there is no drawn signature and no image.

Suggested: make the copy match, or add the features (custom order, a Merge step, a drawn signature).

**P2 #3: Locale pages untranslated.** All 10 hreflang pages (es, pt, fr, de, ja, hi, zh, ko, id + en) show the English H1, intro, price card, FAQ and title; only the nav and one badge change (screens/matrix-locale-*).

**P2 #4: SEO basics.**
- Meta description cut mid-sentence: "…For general office work. Monthly plan with a." It is also used for og:description.
- The title has no "| FreeDailyPro" brand.
- OG image is the site default.

**P3 #5: Weak cross-sell from the steps it bundles.** Only Document Scanner and Organize PDF show a "Keep the whole project: Workflow Product" card for this desk. OCR PDF, Redact PDF, Add Page Numbers, Compress PDF, Merge PDF, Add Watermark and Legal Production Desk pages have no visible link to it (G08).

**P3 #6:** `?checkout=success` shows a guest the payment-confirming message for about 60 s, then it disappears silently (G03, same as #83).

**P3 #7: Guide.** It is titled "Stamp, Number and Hand Off…", but the desk has no stamp step. Its hand-off checklist tells users to unzip and remove `audit-log.csv` and `recipe.json` before sending to a client. Suggested: an "Export for the recipient (documents + manifest only)" option.

**P3 #8: Guest payload.** The full desk, engine, OCR and redaction code (152 KB) downloads for guests who only see the paywall.

**P3 #9:** axe desktop `label-content-name-mismatch` (serious, `.right-2`) and `region`; Pixel 7 `color-contrast` on the ad label text (label contrast only); iPhone SE +9 px; 4 ad iframes before the CTA in tab order.
