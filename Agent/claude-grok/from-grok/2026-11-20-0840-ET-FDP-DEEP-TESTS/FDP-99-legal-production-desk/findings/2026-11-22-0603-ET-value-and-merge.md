# FDP-99 Value at $29.99 / $49.99 and merging with #98

## What the desk adds over the single tools
| Capability | Bates Numbering ($4.99 pass) | Legal Production Desk ($29.99) | Document Operations Desk #98 ($29.99) |
|---|---|---|---|
| Running Bates numbers across files | Yes (+ index CSV) | Yes, skipping withheld rows, with range warnings | No (page numbers only) |
| Stamp options | 6 positions, size, suffix, white box, legend | Fixed bottom-right 10 pt, white box, legend (R5) | n/a |
| Produce / redacted / withheld treatment | No | Yes | No |
| Privilege log (date, author, recipients, description) CSV/Excel | No | Yes | No |
| Production log, withheld list | Index only | Yes | Audit log |
| Cover letter | No | Generated text | No |
| Page-count check before build | n/a | Yes | No |
| Redact / OCR / organize / compress / sign | No | Links only | In-product steps |
| ZIP with manifest + SHA-256 | No | No (logs only) | Yes |
| Matter backup | No | Lists only | Project file |

## Verdict
- **$29.99 alone:** fair for a firm that produces documents regularly (the privilege log and cover letter save real time), but thin next to Adobe Acrobat Pro (about $20/month on an annual plan), which does Bates and redaction in one app. Here redaction, OCR and assembly are separate tools, and on a trial they carry the FDP badge (R4).
- **$49.99:** not justified as it stands.
- **Biggest trust risks:** R1 (hidden pages pass through unstamped) and R2 (attachments pass through). Both were reproduced locally on the desk's own stamp path with #93/#87 outputs. For a legal production these matter more than any feature.

## Merge with #98 (recommended)
One "Document Production Desk" at $29.99:
- **Office mode** (from #98): recipe steps scan, OCR, organize, redact, number, compress, sign; audit log; ZIP + SHA-256 manifest.
- **Legal mode** (from #99): Bates ranges replace page numbers; produce/redacted/withheld; production, withheld and privilege logs; cover letter; legend.
- **Shared:** one fixed engine (no hidden pages, attachments stripped), project file, badge-free output for subscribers, sample packet and video.

Both pages already spend their first FAQ explaining "which desk is for me". A single product removes that and gives the legal buyer in-product redaction and OCR, which is what makes the price easy to accept. A higher tier ($49.99) could then add cloud matters (1 GB, as Event Suite), seats and multi-language OCR.
