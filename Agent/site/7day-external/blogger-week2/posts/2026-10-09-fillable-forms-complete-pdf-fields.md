## Fillable vs flat: know which animal you have

Open the PDF in a normal reader. If you can click into boxes and type, it has real fields. If you can only annotate or type floating text boxes, it may be flat. FreeDailyPro’s Fillable Forms works with **existing form fields**. It does not invent fields on a blank scan. The tool page is honest about that limit—use it when the form was built correctly upstream.

Scanned government forms that are “print and fill by hand” often have no fields. In that case, photograph cleanly, use [Document Scanner](https://www.freedailypro.com/tool/document-scanner), and follow the portal’s handwritten instructions—or request an interactive version if one exists.

## How the workflow feels

1. Download the official fillable PDF from the source (school, employer, agency). Prefer the official file over a random re-upload.
2. Open [Fillable Forms](https://www.freedailypro.com/tool/fillable-forms) and drop the PDF.
3. Complete text fields, checkboxes, dropdowns, and radio groups in the UI.
4. Decide whether to **flatten** on download. Flattening makes answers a permanent part of the page so casual viewers cannot casually edit fields. Use flatten when submitting a final copy; skip flatten if a co-signer still needs to edit.
5. Open the downloaded PDF yourself and verify every answer before you upload.

## Optional flatten: when yes, when no

- **Flatten yes:** final school submission, one-and-done application, file you will email to a counterparty who should not tweak fields.
- **Flatten no:** multi-person review, fields still incomplete, someone else must check a box after you.

If you flatten too early, you may need to start from the blank official file again. Keep the blank original in a `forms-blank/` folder.

## Honest limits

- No fields in the PDF means nothing useful shows up—this is expected, not a bug.
- Complex XFA-only forms or exotic reader features may not map perfectly; test with your actual file.
- This is not a substitute for legal advice about what you should answer on a form.
- Sensitive forms (immigration, medical, financial) deserve policy-compliant handling. Browser-local processing reduces server exposure, but your device, screenshots, and Downloads folder still exist.

Create a short checklist: “Use official PDF. Fill in Fillable Forms. Flatten only when final. Password if emailing. Upload. Delete local copy if policy requires.” Link the tool once. People waste more time finding the right PDF than filling it.

## Government and school portals: extra caution

Always download forms from the official domain. Random “I-9 PDF” search results can be outdated or malicious. After filling, upload only through the portal or address the agency specifies. Fillable Forms helps you complete fields; it does not submit to the agency for you.

## Co-signers and multi-step signatures

If two people must complete different sections, skip flatten until the last person finishes—or use separate sequential downloads only if the form’s instructions allow. Some workflows require wet-ink signatures on a printed flattened copy; follow the form’s instructions over any blog’s generic advice.

## Data you should not casually expose

When a form asks for full SSN, bank routing, or medical detail, minimize who can see your screen. Finish, upload, and remove local copies if policy says so. Browser-side tools reduce server copies; they do not erase shoulder surfing.

## Validating before deadline night

Complete a dry run days early with non-sensitive sample data if the form allows practice. Confirm flatten behavior, checkbox groups, and dropdown values. Deadline night is for answers, not tool discovery.

## When the tool shows no fields

That usually means the PDF is flat. Options: request an interactive version, print and wet-sign as instructed, or use annotation tools only if the recipient explicitly accepts them. Do not fight Fillable Forms to create fields it is not designed to create.

## Accessibility of the answers you type

Use clear, complete answers in text fields. Avoid cryptic abbreviations only you understand. The next reader may be a clerk processing fifty forms an hour. Fillable fields make typing easy; clarity is still your job.

## Employers and HR packets

HR often sends a zip of fillable PDFs. Complete them one file at a time, flatten finals if instructed, then merge only if they asked for a single upload. Merging too early can break field interactivity in some readers—another reason to finish and flatten first when the instructions say “final copy.”

## International characters and names

Type names exactly as legal ID shows, including accents if the field accepts them. If a field rejects a character, follow the form’s help text. Do not “ASCII-ify” a legal name unless the form requires it.

## Backup strategy

Keep the blank official PDF, the filled unflattened working copy if allowed, and the flattened submission copy in separate clearly named files. Storage is cheap compared with redoing a 20-page application.
