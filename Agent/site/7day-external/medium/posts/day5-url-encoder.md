Your campaign URL looked fine in the doc. In the browser it broke at the first space or ampersand. FreeDailyPro’s [URL Encoder](https://www.freedailypro.com/tool/url-encoder) encodes and decodes query strings so UTM links and search URLs survive copy-paste.

## Why links break
Spaces, non-ASCII characters, and reserved symbols need percent-encoding in query values. Humans forget. Platforms double-encode if you encode twice. Decode to inspect; encode once for the final href.

## Workflow
1. Paste the broken or raw URL into [URL Encoder](https://www.freedailypro.com/tool/url-encoder).  
2. Encode values carefully—usually encode query parts, not the entire scheme if tools expect raw structure.  
3. Test in an incognito window.  
4. If JSON configs embed URLs, validate with [JSON Formatter](https://www.freedailypro.com/tool/json-formatter).  
5. For integrity of downloaded assets in the same campaign kit, keep [Hash Generator](https://www.freedailypro.com/tool/hash-generator) nearby.
