## The problem is not “formatting.” It is platform math

Generic formatters treat “print book” as one shape. Real self-publishing is not one shape. Amazon KDP, IngramSpark, Barnes & Noble Press, and Lulu disagree on free ISBN policy, margin rules, and which trim sizes they will accept. Ebook-only routes like Draft2Digital, Apple Books, and Kobo Writing Life do not care about trim size at all.

If you typeset for one platform’s defaults and later decide to expand distribution, you can end up rebuilding margins and cover files. That rebuild is avoidable if platform rules sit at the front of the workflow instead of the end.

Writers often discover this after a cover designer has already delivered a wraparound file. Spine width depends on page count; page count depends on trim and margins. Change the storefront rules late, and you pay twice—once for the interior, once for the jacket.

## The workflow, in order

Here is the path the tool is built around. You do not have to do every step on day one, but this is the logical order when you want a submission-ready file.

1. Pick a publishing platform—or leave Default if you are still deciding. You can switch later without losing chapters.
2. Set up covers and identifiers as the platform requires. ISBN guidance updates with the platform you chose.
3. Write in chapters using the rich-text editor: headings, bold/italic/underline, lists, tables, images with alt text, scene breaks.
4. Toggle front and back matter as needed for your edition.
5. Run free, unlimited Preview—a real typeset render, watermarked, not a vague mockup.
6. Run free, unlimited Pre-flight Check—real render plus real EPUB build checks against the selected platform.
7. Download what you need: clean PDF/manuscript via credits when required; EPUB path has its own free rules described below.

That order is deliberate. Preview before Pre-flight when you want to judge typography. Pre-flight before purchase when you want the checklist against storefront rules. Download last.

## What you actually type into

The editor is a real chapter editor, not a plain textarea. You get bold, italic, underline, headings, lists, tables, images with alt text, and scene breaks. Multi-project support under My Books lets you keep more than one title open; drafts autosave locally in the browser per device.

That last point matters for privacy habits: your drafts live on the device while you write. When you Preview, Pre-flight, or Download, content is sent briefly so the server can do real typesetting; nothing is stored afterward according to the tool’s design. Treat that like any cloud typesetting step—do not paste secrets you would never put in a manuscript.

If you work across two computers, remember local autosave is per device. Export or copy critical drafts when you migrate machines. Free browser tools trade account sync for less signup friction; plan for that trade.

## Platform picker is the differentiator

The publishing platform picker is not a decorative dropdown. Choosing Amazon KDP, IngramSpark, Barnes & Noble Press, Lulu, Draft2Digital, Apple Books, Kobo Writing Life—or Default—changes real behavior.

- Trim size lists filter to what that platform actually supports (including custom entry when the platform allows it).
- Margin math in the real typeset render follows that platform’s rules—for example KDP’s page-count-scaled gutter versus flat margins on other platforms.
- ISBN guidance updates: free platform-exclusive ISBN where it exists, or a clear note that you must buy your own (IngramSpark).
- Irrelevant fields hide for platforms that do not use them.

KDP currently exposes 15 real trim sizes and page-count-scaled gutter margins, with free platform-exclusive ISBN. IngramSpark uses a flat 0.5in margin and does not offer a free ISBN—you buy your own or pay IngramSpark’s ISBN fee (commonly discussed around $25–$49 depending on their offer). Barnes & Noble Press uses flat margins (0.5in, 0.75in inside), a fixed trim list with no custom sizes, and free platform-exclusive ISBN. Lulu uses flat 0.5in margins and free platform-exclusive ISBN. Ebook-only platforms drop print geometry entirely.

> **Tip:** If you are still shopping platforms, start on Default, write freely, then switch the picker before Pre-flight so checks match the storefront you will actually use.

## Free Preview and free Pre-flight—unlimited

Preview is free and unlimited. It is a real typeset render with a watermark—not a thumbnail guess. Pre-flight Check is also free and unlimited. It runs a real render and a real EPUB build, then checks trim size, page count, margin, ISBN, cover resolution, EPUB file size, and accessibility signals against the selected platform.

That combination is meant to catch expensive mistakes before you spend a download credit. If Pre-flight complains about cover resolution or margin, fix it while the download is still free to refuse.

Cover Preview shows a real connected front + spine + back wraparound (watermarked). Looking at the spine after a trim change is not vanity—it is how you avoid a jacket that no longer fits the book block.

## Exports that submission pipelines actually use

On the file side, you can export Shunn Standard Manuscript Format as .docx and .pdf for agent and publisher submissions—12pt Times New Roman, double-spaced, 1in margins, real running head, honest word count. ONIX metadata export is available for retailers and distributors. EPUB 3 export is real; EPUB Accessibility 1.1 / WCAG AA is claimed only when every image has alt text.

Those exports sit beside the print PDF path rather than replacing it. Querying agents? Shunn. Feeding a distributor? ONIX. Selling wide as ebook? EPUB. Printing on demand? Platform-aware PDF after Pre-flight.
