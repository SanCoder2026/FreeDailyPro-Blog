## Steps on Keyword Density

1. Restate the keyword density outcome in one plain sentence before settings.
2. Open [keyword density](https://www.freedailypro.com/tool/keyword-density) and follow live field labels on that page.
3. Feed keyword density production inputs—not demo placeholders you will forget to replace.
4. Treat the first full keyword density output as a candidate, then prove it against the goal.
5. If a secondary tool is required for keyword density, open it only for the blocker you actually hit.
6. Save the keyword density result with a date and purpose in the filename.
7. Do a hostile review of the keyword density result before you announce done.
8. Bag the keyword density run so a second person can reconstruct it.

## Edge cases

Locale and formatting issues can shift meaning after keyword density even when the UI reported success.

Some destinations re-encode keyword density exports—download the stored copy when a portal allows and re-check.

Two keyword density outputs named `download (1)` is how wrong packets ship. Rename immediately.

Odd inputs (partial files, mixed orientations, incomplete rows) confuse operators more than the keyword density UI. Inspect inputs before blaming the tool.

## Mistakes that waste a day

- Skipping the success line and only eyeballing the keyword density result.
- Leaving sample data in a keyword density run that later gets sent as real.
- Chaining five tools when keyword density alone would finish the job.
- Overwriting the only master input while exporting from keyword density.
- Ignoring size/format/length caps until the final keyword density click fails.
- Sending both draft and final keyword density outputs without labeling the authority file.

## Handoff and naming

Name keyword density outputs like `client-or-project-keyword-density-DATE.ext` (adapt extension). Put goal + operator + settings in the ticket that links the keyword density file.

If multiple people share a folder, only numbered keyword density finals are client-facing. Drafts get a `draft-` prefix. That habit matters more than any single click.

## Quality bar
