## What Event Guide is

Event Guide is the installable guest app at `/apps/guest/<link>`. Guests do not create accounts. They open a private link, optionally add it to the home screen, and keep a last copy for offline reading. Tabs: Now, Programme, Venue, News, My pass.

- **Now:** what is running and what is next, in the event time zone.
- **Programme:** by day, with room and speaker; add one session or the whole programme as an `.ics` calendar file.
- **Venue:** name, address, Open map link, organiser notes.
- **News:** announcements you published.
- **My pass:** guest pastes a pass code from the invitation or scans its QR; the pass QR then shows on their screen for door staff. The pass stays on their phone; FreeDailyPro does not learn which guest opened a link.

## Steps: test the guest path yourself

1. Publish the event in Event Suite Premium so a guest link exists.
2. Open the guest link in a clean browser profile on a phone, not only on the laptop that edited the project.
3. Check Now against a wall clock in the event time zone.
4. Open Programme for day one; add one session to calendar and confirm the `.ics` times match the room.
5. Open Venue and tap Open map; fix the address in Event Suite and press **Update** if the pin is wrong.
6. Publish one short News item, press **Update**, refresh the app, and confirm it appears.
7. On My pass, paste a sample pass code from your invitation workflow and confirm the QR draws large enough to scan.
8. Turn on airplane mode, reopen the home-screen shortcut, and confirm the last copy still loads with an offline note if the link was stopped.

## Common mistakes guests hit (and how you prevent them)

- Programme times written in local staff time but the event time zone set wrong, so Now is off by an hour.
- Pass codes emailed as images guests cannot copy; prefer plain text codes plus a QR.
- Relying only on email PDFs and never testing My pass before door open.
- Forgetting News for gate changes, so guests keep walking to a closed entrance.
- Assuming a stopped (revoked) link deletes the last offline copy; guests keep the last copy and see a message when the link is stopped.

## Limits and good to know

- Up to 300 programme items and 100 announcements per published event.
- Published event size up to 2 MB (about 20,000 guests).
- Camera scan quality varies; door staff should use Search by name when a pass will not scan.
- iPhone: Share, then Add to Home Screen. Android: browser menu, Install app.
- Do not promise that every carrier network will load the first open indoors; offline last-copy is the safety net after the first successful load.
