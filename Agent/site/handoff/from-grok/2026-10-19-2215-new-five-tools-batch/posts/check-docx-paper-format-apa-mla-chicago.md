## Why a real format read beats eyeballing

Word's default Normal style is not APA. A paper can "look double-spaced" while still carrying mixed fonts, 1.1-inch margins, or first-line indents that the style sheet rejects. Paper Format Checker opens the file the way Word stores it, not as a guess from word count.

Maya's assignment: APA 7, 12-point Times New Roman or equivalent, double spacing, 1-inch margins, page numbers, running head rules as her instructor specified. She refuses to learn of a margin fail from a TA after the deadline.

## Steps on Paper Format Checker

1. Open [Paper Format Checker](https://www.freedailypro.com/tool/paper-format-checker) in a desktop browser with enough memory for a multi-section paper.
2. Choose **APA**, **MLA**, or **Chicago** to match the syllabus—not a mix.
3. Upload the `.docx` (not a PDF export; the tool reads Word formatting).
4. Wait for the row list: each requirement shows pass, fail, or undetermined with the value the file actually has.
5. Note every fail in a short checklist (for example "left margin 0.95 in → set 1.0 in").
6. Fix settings in Word: Layout → Margins, Home → Font/Paragraph, Insert → Page Number.
7. Save a new version (`…_v4.docx`) and re-upload to confirm fails cleared.
8. Only then run a final spell/grammar pass and export PDF if the portal wants PDF.

## How to read undetermined rows

Undetermined does not mean you failed. Some style rules cannot be proven from every .docx (section breaks, odd headers, or instructor-specific title pages). Treat undetermined as a manual check against the style handout, not as an automatic reject.

## Common mistakes before upload

- Uploading a PDF screenshot of the paper instead of the editable `.docx`.
- Checking MLA when the course still requires APA 7.
- Fixing body text only and ignoring first-page header or page-number position.
- Pasting from email and leaving multiple paragraph styles in one section.
- Burning a trial usage on a half-written draft that will change margins again tonight.

## Instructor portal quirks

Some learning platforms re-flow uploaded DOCX files and break page numbers. After the checker passes, export the PDF your portal prefers and open that PDF once before the deadline. If the portal only accepts DOCX, keep the checked DOCX as the upload and store the checker screenshot or report notes in your assignment folder.

When group papers merge three authors' sections, run the checker after the final merge—not after each solo section—because styles collide at paste time.
