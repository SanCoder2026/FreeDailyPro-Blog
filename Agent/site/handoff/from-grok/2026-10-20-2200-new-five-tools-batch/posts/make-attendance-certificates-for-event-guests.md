## Steps on Certificate Maker

1. Finalize who attended. Do not generate for the full invite list if you only want attendees.
2. Open [Certificate Maker](https://www.freedailypro.com/tool/certificate-maker).
3. Choose the guest set or paste names one per line (max 500).
4. Write short wording using the tool's name, event, and date placeholders. The large name under the title is filled for you.
5. Add up to two signers.
6. Set paper from the project (Letter or A4 landscape).
7. Preview the first certificate—especially a long name.
8. Download One PDF for mass print, or ZIP one-file-each for individual email.
9. Print one page at 100% or Actual size on plain paper before the full heavy-stock run.
10. Keep the project only if you save it; otherwise the tab erases data when closed.

## Wording that still fits

Keep the sentence short so long names fit. Certificates are not essays. A single attended-on-date line beats a paragraph that collides with the signature line.

## Common mistakes

- Certifying every invitee including no-shows.
- Long prose that clips under the name.
- Printing "fit to page" and shrinking margins.
- Expecting logos, seals, digital signatures, or third-party verification—this tool does not do those.
- Skipping the sample print and discovering a misspelled event title on 64 sheets.
- Emailing a single 64-page PDF when people needed individual files (use ZIP).

## Print shop brief

Amira orders heavier stock, Landscape Letter, print at 100%, no "fit to page," and includes a sample PDF page. She keeps the ZIP for email replacements when someone loses a sheet.

## Emailing the ZIP

Name files in a stable order before you attach. Amira uses a mail-merge or sequential send so each guest gets only their certificate. BCC blasts with one ZIP of everyone are a privacy mistake.

## Appreciation vs attendance

If the certificate is "appreciation" for volunteers who may not have a formal attendance flag, select the guest set carefully or paste an explicit name list rather than "everyone invited."

## Two-signer logistics

If the second signer is unavailable the night of the event, print a version with one signer or a clear title line rather than a blank signature block that looks unfinished. Update the project and regenerate only if both signatures are required by the client.

## Workshop series

For multi-week series, generate per session with the session date in the date field, or one series certificate with a date range in the wording—pick one policy and stick to it so certificates do not contradict each other.


## Client brand limits

If a client requires a logo seal, this tool is the wrong path—use their template instead. Certificate Maker is for fast attendance and appreciation certificates without custom artwork.
