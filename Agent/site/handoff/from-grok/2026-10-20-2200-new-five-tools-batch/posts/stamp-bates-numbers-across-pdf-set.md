- Prefix: NBS
- Start: 000001
- Digits: 6
- Files: 38 PDFs in production order (contracts first, email prints second)

- Done definition: continuous numbers across files, index CSV matches file names and page counts, trial mark not required on the production copy

## Steps on Bates Numbering

1. Order the PDFs the way they will be produced. Numbers follow drop order.
2. Open [Bates Numbering](https://www.freedailypro.com/tool/bates-numbering).
3. Set prefix, starting number, and digit width before you drop files.
4. Drop PDFs (or browse). Large files over about 50 MB may be slower or hit browser memory.
5. Confirm numbers can continue from one file to the next when the set is multi-file.
6. Add an optional second line only if counsel approved the exact text.
7. Run the stamp and download the numbered PDFs.
8. Download the index CSV when offered so the production log can cite ranges without reopening every file.
9. Spot-check first page, a middle page, and last page of the last file for continuity.
10. Archive the pre-stamp originals in a restricted folder; send only stamped copies outbound.

## Common mistakes

- Numbering before redaction, then discovering sensitive text still on page 12.
- Dropping files in wrong order and “fixing” by renaming after stamp.
- Assuming Bates stamps make a set court-ready without counsel’s production rules.
- Stamping password-locked PDFs without unlocking first.
- Uploading to a third-party stamp site “just this once” against client policy.
- Skipping the index CSV and reconstructing ranges from memory later.

## Limits and good to know

- Stamping runs in the browser. Files are not sent to a FreeDailyPro server; copies are gone when you close the tab.
- Scanned or rotated pages can be stamped as pages, but OCR and orientation fixes are separate steps.
- Bates numbering is a logistics stamp—not legal advice and not a substitute for court-mandated formats.

## Continuity checks that save Saturday

Nora prints the index CSV and highlights the first and last Bates of each file. If file 17 ends at NBS000842 and file 18 starts at NBS000843, she is done. If a gap appears, she re-runs only from the break with a corrected start number—never hand-edits stamps in a random viewer.

## Second-line legends without clutter

If counsel wants a confidentiality legend, put it on the optional second line only after the exact wording is approved. Do not invent legends for "safety." A wrong legend on every page is harder to fix than a missing one.

When two matters share a war room printer, include the matter short code in the prefix so stacks do not mix (for example NBS vs ORC).

## Supplement productions

For a second production wave, start a new Bates run with a new start number documented in the production letter. Do not reuse the same start on a new set and hope people notice the date.
