## What this tool is (and is not)

Honest scope: new content on top of the page—text, sketches, shapes, highlights. Edit text mode can replace a single text instance in some cases, but this is not a Word-style document editor and not AcroForm filling. For real form fields use [Fillable Forms](https://www.freedailypro.com/tool/fillable-forms); for signatures use [Sign PDF](https://www.freedailypro.com/tool/sign-pdf); lock filled fields later with [Flatten PDF](https://www.freedailypro.com/tool/flatten-pdf).

## Steps on PDF Editor

1. Copy the source PDF; never markup your only archival original in place.
2. Open [PDF Editor](https://www.freedailypro.com/tool/pdf-editor).
3. Upload the working copy.
4. Add highlights on clauses that need verbal confirmation.
5. Draw arrows or ellipses to point at tables or figures.
6. Place short text labels—prefer short notes over essays in the margin.
7. Download and open on a second device to confirm marks survived.
8. Name the file with `_markup` and date so inbox search never grabs the clean version by mistake.

## Review culture that keeps markup useful

Agree that yellow = discuss, red box = must fix before sign, typed notes = questions only. Random colors across a team create noise. Export one markup PDF per review round instead of five parallel annotated copies.

## Common mistakes

- Expecting full paragraph reflow like a word processor.
- Marking the executed final instead of a review copy.
- Covering critical numbers with opaque shapes.
- Forgetting to download after a long session.
- Using annotation when the PDF already has fillable fields that should be filled properly.

## Limits and good to know

- Annotation layer model—great for review, not for rebuilding contracts from scratch.
- Large scanned PDFs can stress browser memory; split if the tab slows.
- File-based tools use the site's trial usage rules (10 trial uses/day on Professional Tools unless you hold a pass or plan).
- Pair with Flatten/Sign/Fill tools when the workflow needs field lock or signatures.
- Always keep an unmarked original for the archive.

- Yellow highlight: discuss on call
- Red rectangle: must change before signature
- Blue text note: internal question only (strip before external send)
- Freehand arrow: point to table/figure, keep short

Export an external-safe PDF without blue notes when vendors are on the thread.

## Version naming

`SOW_vendor_v4.pdf` (clean)
`SOW_vendor_v4_markup_2026-10-20.pdf` (internal)
`SOW_vendor_v5.pdf` (clean after edits)

Never reply-all with an ambiguous `final_final2.pdf`.

## When annotation is the wrong tool

Fillable government forms → Fillable Forms.
Signature blocks that must be real signature fields → Sign PDF.
Need non-editable filled values outbound → Flatten PDF after fill/sign.
Need redaction of secrets → use a dedicated redaction path, not a black rectangle that might still select text underneath depending on method—verify your redaction tool actually removes content.

## Browser memory tips

Close other heavy tabs. If a 200-page scan stalls, split the review into sections and merge comments in a cover note. Prefer digital-born PDFs over 600 dpi full-book scans when you control the source.

## Team review hygiene

One markup owner per round. Collect comments in a 24-hour window, consolidate, send one file. Parallel markups create conflicting arrows on the same clause.

## FAQ-style notes

**Is text fully editable like Word?** No—annotation and limited replace, not reflow layout.
**Can I draw signatures?** Prefer Sign PDF for formal signature workflows.
**Print markup?** Yes for meetings; keep digital master as source of truth.


## External counsel handoff

When outside counsel needs the file, send the clean SOW plus a separate one-page issue list derived from your markup—not a rainbow annotated PDF they must decode. Keep the colorful markup internal unless they ask for visual callouts.


## Meeting packet print

If the Friday call is in a room with weak Wi‑Fi, print the markup PDF with comments visible and number the pages verbally ("page 3 red box"). Bring the clean original on a stick only if live edits will be typed after the meeting. Do not let two people mark paper copies that never re-enter the digital thread.

## Security note for shared machines

Download markups to a project folder, not the public Downloads dump on a shared kiosk laptop. Clear the browser PDF cache on borrowed devices after the session when policy requires it.
