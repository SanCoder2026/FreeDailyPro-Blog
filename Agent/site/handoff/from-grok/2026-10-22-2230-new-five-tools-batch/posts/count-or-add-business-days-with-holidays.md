## Count mode vs Add mode

- **Count:** working days between two dates. Start date is included and end date is not, unless you tick **Count the end date too**.
- **Add:** enter N working days; day one is the next working day after the start (per tool rules). Negative N goes backward.

Weekends: Saturday+Sunday, Friday+Saturday, Sunday only, or no weekend (7-day week). A holiday on a weekend day counts as weekend, not twice.

Holidays are **yours to paste** (`YYYY-MM-DD`, one per line or commas). The tool does not know every country’s public holidays.

## Steps on Business Days Calculator

1. Keep a year of holidays in a notes file for reuse.
2. Open [Business Days Calculator](https://www.freedailypro.com/tool/business-days-calculator).
3. Choose Count or Add.
4. Enter dates / number of working days.
5. Choose weekend pattern that matches the contract.
6. Paste holidays.
7. Decide whether the start day counts (Count mode) and say so in the client message.
8. Copy the result into the quote or SOW.
9. For reverse planning, use negative add to find the latest start date.
10. Re-run if the holiday list or start date changes—do not reuse last quarter’s mental math.

## Say the rule in the email

“Ten business days (Mon–Fri, excluding company holidays listed in Exhibit B), start date counted/not counted as agreed.” Ambiguity about the start day creates disputes. Decide before you quote.

## Common mistakes

- Expecting automatic national holiday databases.
- Mixing calendar days and business days in the same paragraph.
- Ignoring regional holidays for remote teammates.
- Adding more than the tool’s limit (adding is limited to 10,000 working days).
- Counting hours or time zones in this tool—it does not.

## Limits and good to know

- Dates calculated in the browser; nothing uploaded or kept.

## Project management use

Event countdowns, notice periods, payment terms, and lead times all improve when weekends are explicit. Put the calculator screenshot or result line in the project channel for auditability.

## International vendors

When a vendor is in a country with different weekends, state whose calendar governs the SLA. Friday–Saturday weekends change the result of “five business days” dramatically.

## Payroll and notice periods

HR notice math fails when holidays are omitted. Paste the full year list before you tell an employee a final date. Wrong dates create legal and goodwill problems.

## Negative add for back-planning

If a launch is fixed on a Friday, add −15 working days to find the latest start for a 15-day task. That single reverse calc is worth more than a Gantt for small teams.


## Contract language snippet

Suggested clause style: “Business days mean Monday through Friday excluding the holidays listed in Exhibit B; the start date is / is not included as stated in the order form.” Put the calculator result date next to that sentence so nobody re-derives it differently later.

## Quarterly holiday update

Assign one person to refresh the holiday text file each quarter. Stale holiday lists are a silent source of missed deadlines.


## Audit trail for finance

When payment terms are net-15 business days, finance may ask how you got the due date. Keep a one-line note: start date, holiday file version, weekend rule, result. That note ends arguments faster than reopening the calculator under pressure.
