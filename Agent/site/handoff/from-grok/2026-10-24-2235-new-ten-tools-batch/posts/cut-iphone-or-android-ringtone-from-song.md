## Length and format

- iPhone ringtones: up to **40 seconds**; M4R is AAC in an MP4 container with `.m4r` extension.
- Android: no strict universal limit, but **30 seconds** is the usual choice—the Android option stops at 30.
- Fade in/out (for example 0.5 s in, 1 s out) avoids harsh clicks.

## Own recordings

Voice memos and sound effects make great notification tones. Keep levels moderate so the phone speaker does not distort.

## Volume comfort

Phone speakers clip easily. Prefer a slightly quieter export over a “loudest possible” clip that distorts in a pocket.

## Notification vs ringtone

Shorter 5–10 second cuts work better as text tones. Use the same tool with a tighter window for alerts.


## Rights for business use

Personal phone use of a clip you own is different from publishing a ringtone pack for sale. When in doubt, use original recordings or licensed sound effects for anything you distribute.

## Device transfer quirks

iOS M4R install paths change across OS versions; if Finder does not show the tone, check Apple’s current ringtone help for your iOS number. Android file managers vary by OEM—Downloads is not always the ringtone folder.

## Engine cache

After the first engine download, offline clipping still needs the browser cache intact. A privacy browser that wipes storage each session will re-download the engine every time.

## Team on-call tones

Assign distinct short tones per severity for on-call engineers using original beeps rather than chart hits, so a page does not play a full chorus in a meeting.

## Preview before transfer

Play the exported clip on the laptop speakers once. If the downbeat is clipped, nudge the start a few tenths of a second and export again before you touch the phone.

## Storage location note

Write where you filed the M4R or MP3 (`Music/Ringtones/…`). Future swaps take seconds when the file path is known.

## Silence at the edges

Leave a few milliseconds of near-silence after the fade-out so the phone does not click when the file ends. If the source track is brick-wall loud, reduce gain before cutting so the ringtone does not distort on small speakers.

## Multiple phones in one household

Export both M4R and MP3 when family devices mix ecosystems. Keep them in a dated folder so a lost phone rebuild does not require re-finding the chorus start point.

Loop the clip once in headphones before calling it done. Fatigue hides a clipped consonant at the start of a chorus.
