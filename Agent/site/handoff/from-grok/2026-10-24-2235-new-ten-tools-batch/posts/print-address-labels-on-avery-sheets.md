## Why labels print “slightly off”

Almost always printer scaling. Choose 100% or Actual size. If still off, printer margins differ—use My own grid or printer alignment utilities. Among FreeDailyPro’s 200+ professional tools, this is the label-sheet PDF maker.

## Common mistakes

- Fit to page.
- Skipping the plain-paper test.
- Outlines on sticky stock (shows on peel).
- Wrong Avery-equivalent assumption.
- Uploading address lists to random online mail-merge sites when this builds in-browser.

## Limits and good to know

- Labels built in the browser; text not sent or kept.
- File/export usage follows trial rules when this tool counts as a file export on your plan path.
- Measure custom grids carefully with a ruler.

## Partial sheets

Start at label N so the first unused cell is used; later sheets start at the top. Saves money on partial packs.

## International addresses

Longer foreign addresses need fewer lines or a larger label stock. Test the longest address in the batch before committing a full sheet of stickies.

## Return address runs

Fill the sheet with your return address for multipurpose stock. Keep a PDF named `return_5160.pdf` ready for rush shipments.


## Batch from spreadsheets

Paste addresses with a blank line between records. Watch for accidental double blank lines that create empty labels and shift the sequence when you thought you were starting at label 5.

## Ink and smudge

Allow shipping labels a minute to dry before stacking boxes. Dense barcodes and small type smudge when boxes slide in a bin.

## Return vs shipping stock

Keep separate PDF masters for return address sheets and destination sheets so you never print customer addresses on return stock by mistake during a rush.

## Inventory of partial sheets

Write the next label number on the pack sleeve with a marker. The Start at label control only helps if humans remember where they stopped.

## Quiet hours printing

Laser heat can curl thin label sheets. Print small batches and let them cool flat under a book before peeling.

## QR on separate insert

If you need a QR, print it on card stock separately rather than cramming unreadable codes onto tiny address labels.

## Special characters

Accents and long hyphenated street names need a font size that still fits. Print the five longest labels as a stress test before a 500-piece run.

## Nonprofit mailings

When volunteers help, give them the test-page ritual in writing: 100% scale, plain paper first, then sticky stock. One misfit sheet wastes more money than the two minutes of training.

## Handwriting hybrid

Some teams print only the address block and leave a blank line for a short personal note. Test that layout so the note line still sits inside the sticky area.

## Box corner placement

Place labels on a flat face, not over tape seams, so scanners and humans can read them after transit scuffs.
