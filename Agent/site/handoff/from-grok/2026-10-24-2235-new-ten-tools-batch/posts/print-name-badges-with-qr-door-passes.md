## Offline door behaviour

Door check runs on the device where the project is open. Passes are not checked live across devices. For multi-door live ticket systems, use dedicated ticketing instead.

## Common mistakes

- Printing badges, then editing the guest list without re-exporting.
- Forgetting to save/copy the project to the door laptop.
- Fit-to-page printing that misaligns badge stock.
- Expecting cross-device live counts without a heavier system.
- Closing the tab without a project file backup.

## Lanyard logistics

Print extras for walk-ups; keep a “void and reissue” process so a lost badge does not mean a forged pass without project control.

## Walk-up guests

Leave blank badge stock and a re-export path. Add walk-ups to the project, save, print a single sheet, and keep door validation in sync.

## Privacy at the door

Do not project the full guest list on a public monitor. Door staff need the tool UI, not a slideshow of emails.


## Role lines on badges

Add role or company under the name when the event mixes staff, press, and guests. Door volunteers sort problems faster when the badge states the category without opening a spreadsheet.

## Printer calibration

Laser printers sometimes scale subtly even at “100%.” The plain-paper hold-over test against real badge stock catches that before you waste a full box of inserts.

## Lost badge protocol

Mark the old pass as void in your process notes, add a replacement guest line if needed, re-export a single badge, and tell door staff the new QR is the only valid one. Chaos happens when both old and new scan as valid because the project still lists both.

## After-event deletion

When the event ends, archive the project offline if you need attendance records, then clear browser data on shared laptops so the next client event does not open the previous guest list.

## Name length overflow

Extremely long names need a smaller type tier or two-line layout. Check the five longest names in the CSV before the full badge PDF runs.

## Staff badges first

Print staff and volunteer badges in a different colour band if the layout allows, so door teams spot helpers quickly.

## Pronouns and preferred names

If your CSV includes preferred names, print those on the badge and keep legal names only in the private project fields. Guests notice respect; door staff still need the project to match the QR.

## Backup scanner device

Charge a second phone with the project file installed the night before. Door lines form when the primary tablet hits five percent battery.
