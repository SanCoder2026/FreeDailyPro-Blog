- Never saving the project, then losing door validation.
- Ignoring dietary fields until the caterer asks at 4 p.m.
- Expecting multi-door live sync without the right product tier/system.
- Uploading guest CSVs to random “helpers” when this flow keeps data in-tab until you save.

## Staff briefing

Train door volunteers on Valid vs already-checked behaviour and how to search when a QR will not scan. Paper backup list still helps.

## Access needs early

Capture mobility and access needs with the same care as dietary fields. Venue staff need lead time for seating and routes—not a surprise at the door.

## Label vs badge

Badges identify people; labels identify seats or gifts. Generate both from the same list so spelling never diverges.


## Caterer summary timing

Send the dietary and access summary 72 hours before, then a final delta 24 hours before. Kitchens plan protein counts early; last-minute vegan spikes need a written change log.

## Import column mapping

When you import CSV, map name, email, dietary, and access fields carefully once, then save a cleaned CSV as the master. Re-importing messy originals reintroduces typos onto badges.

## Multi-day guest reuse

For multi-day conferences, keep one project and note day credentials on the badge line rather than building three guest lists that diverge by Wednesday.

## Volunteer shift handoff

Door shift A exports a simple “checked in so far” note if your process needs it; shift B opens the same project. Verbal handoffs without the project file create double admits.

## Plus-ones policy

Encode plus-ones as separate guest rows with a link note, not a plain-text blob in the primary name field. Badges and door check both behave better with atomic rows.

## Rain plan registration

If outdoor check-in moves inside, the same project still works—practice opening door check on the backup tablet the night before.

## Kids and minors

If minors attend, decide badge rules and guardian links before import. Do not invent policy at the door while a queue waits.

## Post-event thank-you list

Export attendees who checked in if your process allows, then run thank-you email from your own mail tool. Keep the project archive with the date for next year’s invite list.
