## Exhibit labels vs Bates numbers

Bates numbering gives every **page** a running number. The Exhibit Stamper labels each **document** as an exhibit. Many productions use both: stamp exhibits first, then Bates the production set. ## Steps on Exhibit Stamper

1. Finalize the exhibit order offline (party A letters, party B numbers if the forum expects that).
2. Open [Exhibit Stamper](https://www.freedailypro.com/tool/exhibit-stamper).
3. Drop PDFs in exhibit order (files over about 50 MB may stress browser memory).
4. Choose **First page only** or **Every page** (with optional “page 2 of 5” style after the label).
5. Run the stamp and download stamped files.
6. Download the CSV index (label, original name, stamped name, page count, empty Description).
7. Fill Description before attaching the index to a filing.
8. Redact sensitive pages with [Redact PDF](https://www.freedailypro.com/tool/redact-pdf) **before** final stamp when needed.
9. Merge a cover + exhibits with [Merge PDF](https://www.freedailypro.com/tool/merge-pdf) only after stamps are correct.
10. Archive stamped set + filled index with the case file name and date.

## Common mistakes

- Stamping before redaction, then re-stamping the whole set.
- Mixing letter and number schemes without a party key on the index.
- Leaving Description empty so the index is only filenames.
- Treating exhibit stamps as Bates page control.
- Closing the tab before downloading—the work is not stored by FreeDailyPro.

## Forum conventions

Some courts want letters for movant exhibits and numbers for respondent. Put that rule in the Description header of your index template so interns do not invent a third scheme mid-packet.

## Insurance and admin uses

Claim packets, licensing applications, and board books also need exhibit labels. The same stamp-and-index loop works outside litigation—just keep naming consistent with the cover letter.

## QA before e-file

Open three random stamped first pages. Confirm label placement does not cover critical text. If it does, adjust placement options if available or re-export source PDFs with more margin.

## Label placement discipline

If a stamp covers signatures or docket text, regenerate source PDFs with extra top margin before the next stamp pass. Fixing placement after e-file is far more expensive than a second browser pass.

## Dual-party packets

When both sides exchange exhibits, keep two indexes: Movant A–F and Respondent 1–8. Never renumber the other side’s exhibits in your own index.


## Hearing binder assembly order

A practical stack order for many US mediations: cover letter, index with filled descriptions, then stamped exhibits in letter order. If you merge into one PDF for e-file, merge only after stamps and redactions are final so you do not re-stamp a combined file blindly.

## Filename conventions that survive email

`CaseName_ExB_EmailThread_stamped.pdf` beats `scan2.pdf`. The index CSV should list the stamped file name exactly so a clerk can match downloads without opening every file.

## When exhibits arrive late

Stamp late arrivals as the next letter, update the index row, and send a short “index v3” note. Do not renumber earlier exhibits already cited in briefs.

## Redaction coordination

If only three pages of a fifty-page PDF need redaction, split those pages, redact, rejoin, then stamp the whole exhibit once. Stamping first freezes visual layout that redaction might shift.

## Colour vs grayscale stamps

If e-file rules prefer grayscale, confirm stamps remain legible when printed mono. A light teal stamp that vanishes in black-and-white helps no one.

## FAQ

**Every page or first only?** Either—choose based on forum preference.

**Uploaded?** No—browser stamping only.

**Different from Bates?** Exhibits label documents; Bates numbers pages.
