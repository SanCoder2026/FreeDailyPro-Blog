## Why HEIC shows up and when JPG still wins

iPhones save HEIC by default because files are smaller. Many websites, older desktop programs and email gateways still expect JPG. In iPhone Camera settings, Most Compatible saves new photos as JPG if you prefer that going forward—but you still need conversion for the library you already shot. JPG is lossy, so there is a small quality change; keep the HEIC original when archival quality matters. PNG keeps more fidelity and transparency; WebP is often smaller for web; PDF is handy for single-page handoffs.

## Common mistakes

- Deleting HEIC originals before confirming the JPG set is complete.
- Uploading full-resolution JPGs to a form that caps file size, then blaming the converter.
- Converting screenshots that were already PNG for no reason.
- Assuming conversion improves a blurry photo—it only changes container/format.
- Leaving converted client photos on a borrowed computer.

## Edge cases

## Choosing JPG vs PNG vs WebP vs PDF

Pick JPG for portals, email and most forms. Pick PNG when you still need lossless detail or transparency for further editing. Pick WebP when the destination is a modern website that accepts it and you want smaller files. Pick PDF when a single photo must travel as a one-page document for a desk that refuses image attachments. After conversion, run a quick open test on the target device class (Windows laptop, Android phone, older browser) before you delete anything from the camera roll.

## Client delivery folders

Create a dated folder with originals/ and delivery/ subfolders. Convert only into delivery/, leave HEIC masters untouched, and zip delivery/ for the client. That habit prevents accidental master deletion when cleaning “downloads.”

## Real-estate and insurance packs

Adjusters and portals often reject HEIC silently. Convert the set, name files room-angle-date, and upload JPG. Keep HEIC for archival reprints of key rooms. For insurance claims, store both the converted set and a text note of the conversion date so you can explain file lineage if asked months later.

## Email size traps

A dozen full-resolution JPGs still bounce off small mailboxes. After conversion, compress the delivery set, or send a ZIP. Never compress the only master—work on copies in the delivery folder.

Batch conversion is ideal after a shoot day, not during upload panic. Build a habit: dock phone, copy HEIC to a dated folder, convert a delivery set, upload, archive. The panic pattern produces half-converted folders and missing angles.
