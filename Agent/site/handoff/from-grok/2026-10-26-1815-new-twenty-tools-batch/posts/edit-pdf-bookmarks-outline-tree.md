## What the editor changes—and what it does not

You edit titles, page numbers, order and nesting. The eye button previews the page a bookmark points at. Add a bookmark with a title and page number. Bookmarks save so each opens its page fitted to the window; original zoom or scroll positions are not kept. Named destinations without page numbers show no page until you type one. The tool does not auto-build bookmarks from headings and does not edit page content, links or form fields. Password-protected PDFs must be unlocked first. Remove all clears the outline on download.

## Common mistakes

- Editing page content expectations—this tool only touches the outline.
- Leaving bookmarks pointed at wrong pages after a late page insert (re-merge then re-edit).
- Deep nesting that confuses readers; prefer two levels for most reports.
- Forgetting that zoom positions reset to fit-page.
- Overwriting the only copy of a signed PDF; always keep the original.

## Edge cases

Scanned books: add chapter bookmarks manually at chapter starts. Multi-language titles: keep reader language consistent. Very large PDFs: edit after splitting if the browser struggles, then merge.

## Outline style guide

Use Title Case short labels, match the printed table of contents wording, and avoid bookmark spam for every minor subheading.

## Outline after merge, not before

If you still expect to merge or organise pages, finish page order first, then bookmark. Bookmarks that point at moving targets create support tickets. After edits, open the downloaded file in a second reader (browser PDF view and a desktop reader) to confirm jumps. For client deliveries, include a one-line note: “Use the outline panel to jump sections.” Many recipients never discover bookmarks unless told.

## Naming bookmarks for skimmers

Prefer “3. Pricing assumptions” over “Section 3.” Readers open outlines under time pressure. Mirror the printed table of contents wording so print and screen navigation feel like one document.

## Reports assembled from many authors

Merged chapter PDFs often inherit meaningless bookmarks from each source. Strip or rebuild the outline after [Merge PDF](https://www.freedailypro.com/tool/merge-pdf) so the combined file has one coherent tree. Indent subsection bookmarks under chapter titles; avoid ten levels of nesting that collapse into noise on small screens.

## Accessibility and findability

Descriptive bookmark titles help keyboard and screen-reader users move through long PDFs faster than hunting page numbers. Align titles with heading language in the body so the outline is not a separate dialect.

After you download, open the outline in two readers and click the deepest nested item and the first top-level item. If either fails, fix page numbers before you send the file to a client. When removing all bookmarks, say so in your delivery email so recipients are not surprised by a flat PDF.

For books converted from scans, place chapter bookmarks at the first page of body text for each chapter, not on decorative half-titles, unless the reader needs those half-titles. Consistency beats decoration.

## Delivery checklist for client PDFs

Before you send, confirm: outline opens, first and last bookmarks jump correctly, no leftover “Page 12” titles, and the file name includes version and date. If the client will print, bookmarks still help on screen proofs. Add page numbers with the related tool only after the page order is final so bookmark targets stay true.
