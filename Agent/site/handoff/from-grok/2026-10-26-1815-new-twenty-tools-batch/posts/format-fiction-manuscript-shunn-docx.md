## What Shunn-style usually means

Times New Roman 12 point, double spaced, 1 inch margins, first-line paragraph indents, a title page with contact details and approximate word count, and a running head with last name / TITLE / page number on later pages. Bold and italics are kept; colours, alignment, images and tables are dropped because standard manuscripts do not use them. Always read the agent, magazine or publisher guidelines—some want different fonts, no contact block, or a synopsis first. Their rules win over any template.

## Common mistakes

- Submitting without reading the market’s unique rules.
- Leaving sample placeholder contact data on the title page.
- Expecting images or complex tables to survive—strip them before upload.
- Trusting the in-tool page estimate instead of the processor’s count after styles apply.
- Sending a file named final-final-v3.docx instead of Title_Author.docx.

## Edge cases

Multiple POV parts: keep part titles as chapter-style headings the tool detects. Novellas under 40k: still use standard format unless guidelines say otherwise. Simultaneous submissions: keep identical manuscript bodies; only cover letters change.

## After acceptance

Production interiors are a different job from submission manuscripts. Do not send your Shunn file straight to a print-on-demand interior without reformatting.

## Market checklist before you hit send

Confirm file type (.docx vs PDF vs RTF), font exceptions, whether a synopsis is separate, anonymity rules for contest entries, and simultaneous submission policy. Name the file with title and author surname. Disable editorial comments and tracked changes. If you use Manuscript Formatter and then tweak margins for a rare guideline, document the exception so your next submission can reset to standard format quickly.

## Scene break markers

If your draft uses decorative scene breaks, replace them with a simple # or blank line convention the formatter preserves as text, then verify in the .docx that scene breaks still read cleanly when double-spaced.

## Italics, thoughts and emphasis

Shunn-style manuscripts keep italics for emphasis and internal thoughts when your style uses them. After download, search the .docx for leftover ALL CAPS emphasis that should be italics, and for accidental double spaces from paste. Do not add headers with fancy fonts—the running head is enough.

## Simultaneous submissions tracking

Keep a simple log: market, date sent, manuscript version hash or filename, response due. When you revise after a rejection, bump the version in the filename so you never resend an old draft to the same editor by mistake.

Before uploading chapters, strip comments, tracked changes and text boxes. The formatter rebuilds layout from text; hidden review clutter can produce odd spacing. Chapter titles should be plain text headings your source already uses so the tool can count chapters correctly.

If a market wants a synopsis as page one, prepare that as a separate file rather than overloading the title page. Standard manuscript format is already doing a lot of work; do not invent a hybrid that confuses first readers.
