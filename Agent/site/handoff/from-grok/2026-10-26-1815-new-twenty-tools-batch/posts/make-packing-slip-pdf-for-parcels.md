## Packing slip vs invoice

A packing slip says what was sent. An invoice says what is owed. Customers and warehouse staff need the first without always seeing the second. Each line includes a Packed checkbox you can tick on paper while packing. Long lists continue on extra pages. The PDF is built in the browser; nothing you type is uploaded or stored by FreeDailyPro.

Order 1842 ships three SKUs: chain, charm, polishing cloth. The seller enters shop return address, customer ship-to, order number, ship date and quantities. They print two copies, tick Packed as each item goes in, seal the slip under the tissue, and file the second copy. Invoice emails separately from the shop platform.

## Common mistakes

- Putting prices on a packing slip when the customer should only see them on the invoice.
- Vague descriptions (“item 1”) that do not match the storefront name.
- Forgetting the order number so support cannot match a return.
- Using the slip as a courier label—it is not a shipping label and does not book a carrier.
- Editing totals by hand after download until paper and PDF disagree.

## Edge cases

Partial shipments: state which lines ship now in the description notes. International orders: add customs-friendly plain descriptions. Kits: list components if the customer expects to verify each piece.

## Pick-and-pack desk setup

Screen with order, printer with slips, label sheet for addresses, bin for packed boxes. Tick slips in the same order every time to reduce misses.

## Returns and partials

When a line is back-ordered, print a slip that lists only what is in the box and add a plain-language note about the rest. Customers who receive a slip that claims five items but find three lose trust faster than customers who see an honest partial list. For returns, ask them to include the slip or order number; matching becomes trivial when the paper still carries the id.

## Multi-item quality control

For kits, tick components in the same order every time. A second person spot-checking high-value orders against the slip catches swaps before postage. If you pack from a phone screen, still print the slip—the paper travels with the box when the phone does not. Store a digital copy named orderid-pack-date.pdf next to the platform order export.

## Insert slip placement

Place the slip on top of goods under the first tissue layer so opening the box reveals it immediately. Slips buried under filler get discarded with packaging and then customers open tickets.

## Hazardous and fragile notes

If an item needs “this side up” or fragile handling, put that in the line description so warehouse staff see it while packing—not only on a separate sticker they might miss. For multi-box orders, print one slip per box listing only that box’s contents, and mark Box 1 of 2 on the slip header notes if you add them.

## Marketplace channel differences

Some channels already inject packing slips. Use this generator for direct-to-customer web orders or wholesale cartons that need a clean plain-language list without channel branding.

Wholesale cartons may need packing slips that list inner assortments. Write clear component lines rather than a single SKU nickname only warehouse staff understand. Retail customers reading a slip should recognise product names from the storefront.

If you include open gifts, list them with quantity so the customer does not think a missing invoice line means a packing error. Keep prices off the gift lines as with all packing slips.
