## Stage mode vs Focus mode

Stage mode: type a length such as 5, 5:30 or 1:05:00, set when amber and red warnings start, and press Start. Use Full screen on a second display or a tablet facing the speaker. Green means plenty of time; amber is the first warning; red is the final warning; dark red with a plus sign means overtime. A short beep can mark each change if sound is on. Focus mode alternates work rounds and short breaks, with a longer break after several rounds; lengths are yours to set. The timer follows the clock, so it stays correct even if the screen sleeps briefly, and it asks the browser to keep the screen awake where allowed.

## Steps for a live stage countdown

1. Open [Focus Stage Timer](https://www.freedailypro.com/tool/focus-stage-timer).
2. Choose Stage mode.
3. Enter duration (minutes, mm:ss or h:mm:ss) or a preset.
4. Set amber and red warning thresholds the speaker agreed to.
5. Test sound once in the empty room.
6. Press Full screen on the display the speaker will face.
7. Start only when the speaker begins, not during walk-on music unless planned.
8. Keep the tab open and the device plugged in.
9. When time is up, use overtime visibility so the moderator can intervene calmly.
10. For multi-session days, advance with agenda/Next session when configured.

## Common mistakes

- Starting the timer during applause so the talk is short-changed by a minute.
- Facing the countdown toward the audience instead of the speaker.
- Relying on a half-charged tablet that dies mid-keynote.
- Skipping a sound check, then surprising the room with a loud beep.
- Using Focus mode lengths that never match how you actually work, then abandoning the tool.

## Edge cases

If the venue blocks full screen on shared machines, open the page on your own tablet. If two timers run (stage and stream delay), designate one as authoritative for the speaker. For accessibility, ensure contrast of the full-screen colours is readable under stage lights—test in the actual room.

## Focus mode quick recipe

Set 25-minute work and 5-minute break, longer break every four rounds. Start the next round automatically only if you will stay at the desk; otherwise require a click so breaks stay real.

## Room test checklist before doors open

Walk the actual sightline from the lectern to the timer display. If sunlight washes the screen, increase brightness or relocate the tablet. Confirm the full-screen gesture works on the device you will use live—not only on the ops laptop. Disable notifications on that device so a message does not cover the digits. Agree with the speaker whether amber means “wrap the story” or “one more slide,” and put that agreement in the run-of-show notes so a substitute moderator does not invent a new meaning mid-talk.

## Multi-speaker panels

For panels, run one stage timer for the full segment and a second silent phone timer for per-speaker soft limits if needed—but only one full-screen display faces the stage to avoid conflicting numbers. Brief the moderator on who owns the overtime decision. Focus mode between sessions helps ops staff process badge queues without drifting into endless Slack.

If the stage display fails, have a printed card with remaining minutes updated by a stage manager every five minutes as fallback. Technology is primary; paper is insurance. Test full screen on the exact device and browser the week before, not during soundcheck only.

For hybrid streams, do not show the speaker-facing timer on the audience livestream unless that is intentional design.
