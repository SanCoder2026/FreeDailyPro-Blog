## What a cue sheet is

A crew-facing timeline: who walks on, when mics open, when slides change. Guests never see it. Mixing cue language into the guest programme confuses both audiences.

## Stage timer etiquette

Show speakers the timer rules in rehearsal. A clock that appears only when they are already overtime creates panic, not pacing.

## Break blocks

Put coffee and lunch as real sessions with end times so the timer and clash logic treat them as sacred, not optional.

## Multi-room days

Name rooms consistently with signage. If two sessions share a speaker, the end times make travel conflicts visible before you print.

## Version labels

Name exports Programme_v3 and Cues_v3 the same day so registration does not print yesterday’s PDF from Downloads.

## Production log

Write one line of settings and export date next to the final file for the build run of show cue sheet and timer job so a reprint does not start from zero.

## AV channel notes

Put talkback channel and who owns slide clicker on the cue sheet, not in a Slack thread. When the network dies, paper still directs the room.

## Overrun policy

Write the overrun rule once: hard stop, soft stop with next session shortened, or float into break. The timer is useless without a policy speakers heard in rehearsal.

## Rehearsal capture

During tech rehearsal, annotate the cue sheet with actual walk times from green room to mark. If the walk is ninety seconds, the paper must show it or the timer will lie. Update end times when walk times blow a previous assumption.

Give the stage manager a laminated cue sheet and a pencil. Digital-only cues fail when the only laptop is driving slides.

## Extra field practice

Build a speaker packet that includes the printed agenda page for their slot and the overrun rule in one paragraph. Speakers who only see the marketing website will not know hard-stop policy. Put backup slide owners on the cue sheet so a missing laptop does not freeze the room. If you run hybrid streams, add a line for when the stream goes live versus when doors open—those times often differ by ten minutes and confuse chat moderators.
