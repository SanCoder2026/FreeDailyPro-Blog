## Certificate privacy

Do not publish a wall of email addresses on certificates. Name and event title are enough for most training days.

## CRM fields

Guest summary should include opt-in status if you have it. Thank-you mail without consent creates compliance noise.

## Certificate reprint policy

Decide in advance whether misspellings get no-cost reprints and how guests request them. Publish that policy with the certificate email so ops is not inventing answers under pressure.

Zip certificates by last name when emailing in bulk so staff can find one file quickly.

## Archive and naming for close event with report and certificates

Store final exports under a folder named with the event or project code and the ISO date. Inside, keep `exports/`, `project/`, and `notes.txt`. In notes.txt for close event with report and certificates, record approver name, device used on the day, and version label. That beats a desktop full of final2 copies.


## Extra field practice

Sequence the close-out: freeze guest names, export certificates, send guest summary to CRM, generate closure PDF, then refresh profit after last costs post. Reversing that order causes certificate reprints and finance churn. For multi-day training, put the day range on certificates so attendees can prove which session they finished. Store a hash or simple file count of the certificate folder in notes so you know if someone later deleted a file.


## Capacity and contingency

For close event with report and certificates, write a short contingency: if the primary laptop fails, which backup device opens the project; if the printer fails, which file is already on a USB stick; if the venue network fails, which steps still work offline. Contingencies written after the failure are just stories. Contingencies written before the event are operations.

Assign names, not roles only—roles change when people call in sick. List those people by name in the notes file that sits beside the close event with report and certificates export.

## Certificate delivery channel

Email certificates as PDFs named Lastname_Firstname_Event.pdf when privacy allows, or distribute from a desk with ID check for high-stakes credentials. Never post a public folder of everyone’s files without access control.
