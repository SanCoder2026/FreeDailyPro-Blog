## Weighted score honesty

Write what the weights mean once. If price is 60% and service 40%, stick to it so post-event arguments do not rewrite history.

## Deposit cash flow

A low headline price with a huge early deposit can hurt more than a higher quote with fair terms—capture both fields before you accept.

## Packing slip ritual

One person checks quantity and damage on arrival and signs the slip. Photo the pallet if anything looks off.

## Multi-currency events

Only compare like currency in one view, or convert offline and note the rate date next to the quote.

## Vendor memory

After the event, rate vendors while memory is fresh so next year’s comparison starts with real notes.

## Production log

Write one line of settings and export date next to the final file for the compare vendor quotes and raise pos job so a reprint does not start from zero.

## Single owner for POs

One person raises POs. Two people raising partial POs against the same quote creates double orders and angry vendors.

## Quote expiry dates

Capture expiry on each quote. A “winner” that expired last Tuesday is not a winner—it is a renegotiation.

## Scorecard archive

After you accept a quote, export the comparison view or screenshot the side-by-side with weights visible. Auditors and future you need to see why the higher AV bid won on risk, not only the final PO number.

When deliveries partial-ship, note short ships on the packing step the same day so budget remaining is real before the event weekend.

## Archive and naming for compare vendor quotes and raise pos

In notes.txt for compare vendor quotes and raise pos, record approver name, device used on the day, and version label. That beats a desktop full of final2 copies.


## Extra field practice

Create a vendor folder per category—AV, catering, security—with quote PDFs renamed to vendor_date_amount. Link those filenames in the quote manager notes field when available. If a vendor requires a deposit wire, log the wire reference next to the deposit percent so accounting can match bank lines without guessing. On delivery day, photograph damaged goods before signing the slip; memory fades by the time disputes open.


## Capacity and contingency

For compare vendor quotes and raise pos, write a short contingency: if the primary laptop fails, which backup device opens the project; if the printer fails, which file is already on a USB stick; if the venue network fails, which steps still work offline. Contingencies written after the failure are just stories. Contingencies written before the event are operations.

Assign names, not roles only—roles change when people call in sick. List those people by name in the notes file that sits beside the compare vendor quotes and raise pos export.
