## Why .ics matters

Guests who only read the card still mistype times. Opening .ics places the event with a reminder in their calendar app.

## Time zone text

Write the city and time zone in the card body when guests travel. .ics carries structured time, but humans still read the card first.

## Physical + digital

Print cards for VIPs and email .ics to everyone. Mixed audiences need both channels without conflicting times.

## Dual-client test matrix

Test .ics on at least one Apple Calendar and one Google Calendar account before bulk send. Outlook desktop quirks deserve a third test if many guests are corporate.

If doors open thirty minutes before start, say so in both the card body and the calendar description field.

## Extra field practice

If the event spans time zones for remote guests, put the primary city clock on the card and include a world-time link in the email body. Calendar files should still use correct structured times for the venue zone. For multi-session days, either one .ics with a clear description or separate files per major block—pick one rule and keep it for the whole guest list.

For make invite card and calendar ics, write a short contingency: if the primary laptop fails, which backup device opens the project; if the printer fails, which file is already on a USB stick; if the venue network fails, which steps still work offline.
