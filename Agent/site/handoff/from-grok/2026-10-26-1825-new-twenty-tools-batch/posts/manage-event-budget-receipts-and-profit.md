## Same-day capture rule

If a cost is not entered the day it happens, it often never appears—and profit lies upward.

## Merch as cost

Merchandise is not zero-cost marketing. Log deposit and balance so profit reflects real cash.

## Crew fairness

Timesheets protect both the organizer and the crew. Round rules should be written once.

## Currency discipline

Pick a project currency. Convert foreign receipts offline with a rate date note.

## Board pack

Export the profit statement plus top five variances with one sentence each—do not dump raw lines into email.

## Production log

Write one line of settings and export date next to the final file for the manage event budget receipts and profit job so a reprint does not start from zero.

## Petty cash envelope

If volunteers spend cash, photograph receipts before they crumple and enter them the same night. Missing receipts become mystery variance.

## Merchandise returns

Log returns as negative costs or adjustments with a note. Silent returns make profit look better than cash reality.

## Variance narrative

When the profit statement surprises you, write three variance bullets the same day: what moved, why, and whether it is expected to reverse. Numbers without narrative get misread in board chat.

Crew timesheets should close within twenty-four hours of load-out while hours are still remembered accurately.

## Extra field practice

Photograph receipts in a dedicated album named by date, then enter amounts before the album backs up to personal cameras that leave with volunteers. Tag each expense with a budget line at entry time; recoding hundreds of lines after the event is how profit statements slip a week. Merchandise preorders need a separate line so unsold stock does not hide inside “misc supplies.”

For manage event budget receipts and profit, write a short contingency: if the primary laptop fails, which backup device opens the project; if the printer fails, which file is already on a USB stick; if the venue network fails, which steps still work offline. Contingencies written after the failure are just stories. Contingencies written before the event are operations.
