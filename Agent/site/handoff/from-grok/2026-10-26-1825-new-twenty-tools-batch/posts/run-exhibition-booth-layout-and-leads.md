## Lead sheet discipline

Number sheets by booth. Collect them nightly. Type leads the same evening so follow-up does not wait a week and handwriting is still readable.

## Badge vs exhibitor company

Print company names large enough to read across an aisle. Staff first names matter for networking; legal entity names matter for contracts—put both when space allows.

## Load-in paper

Print two layout pages: one for the dock, one for the floor manager. Phones die in concrete halls; paper still works.

## Partial payments

If deposits are allowed, record them clearly so “Paid” only means fully settled. Partial rows need a next-action date in your offline chase list.

## Exhibitor portal myth

This tool does not host a public exhibitor portal. Send PDFs and sheets offline; keep the master project private to your team.

## Production log

Write one line of settings and export date next to the final file for the run exhibition booth layout and leads job so a reprint does not start from zero.

## Staffing the lead desk

If you collect leads centrally, staff a quiet table away from the loudest aisle. Exhibitors still get sheets, but a central scan station reduces lost clipboards.

## Nightly reconciliation

Each night, reconcile badges printed versus staff on site. Extra badges walking the floor without names are a security smell at larger shows.

## Lead sheet return path

Print sheets with booth number, exhibitor company, and a return-to-ops box. Nightly, photograph each sheet before typing if handwriting is marginal. Morning, give exhibitors a count of leads captured so they see value beyond the rental fee.

Badge lanyards for exhibitor staff should use a different color band when the layout allows, so security can spot non-attendee workers quickly during late teardown.
