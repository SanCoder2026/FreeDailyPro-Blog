## Interior QA grid

Check page one of every chapter for stacked headings, check a random middle spread for gutter collision, and check the last page for an accidental blank that forces an odd count. Fix source chapters, then regenerate—do not patch the PDF by hand if you still need another export later.

Keep a `interior_settings.txt` next to the PDF listing trim, font choice if shown, and date generated.
