## Fixed order (live product)

The studio always works in this sequence:

1. Change slide size
2. Add slide numbers
3. Stamp a watermark
4. Accessibility check (checks and reports; it does not auto-rewrite your story)
5. Clean for sharing
6. Compress

You tick the steps you need; order stays sensible so numbers land after size changes and compression comes last.

**Authoring** still starts in [Slide Deck Maker](https://www.freedailypro.com/tool/slide-deck-maker) or your desktop app. Studio does not invent slides.

## Browser vs server conversion note

Only **`.pptx`** stays entirely in your browser. Other presentation types (`.ppt`, `.pps`, `.pot`, `.odp`, `.otp`, `.key`, and similar) are **sent to FreeDailyPro servers first**, converted to `.pptx`, then delivered for the studio steps. Plan privacy accordingly: keep confidential decks as `.pptx` when you need on-device-only processing.

## Clean for sharing without deleting your master

Alex keeps an internal master with full notes. The “clean for sharing” export is a **send copy**. He never overwrites the only master file in cloud storage with the cleaned output.

If a partner asks a follow-up question that lived only in speaker notes, MASTER still has the answer.

## Two-file naming Alex uses

`Partner-Name-2026-Q4-MASTER.pptx` and `Partner-Name-2026-Q4-SEND.pptx`. Studio output always becomes the SEND name. MASTER stays local with notes intact. When a draft watermark is active he appends `-DRAFT` so nobody confuses it with the final.

## Common mistakes

- Expecting Studio to write the deck from an outline (use Slide Deck Maker).
- Dropping a `.key` file without reading the server-conversion privacy note.
- Watermarking the final customer copy by accident.
- Skipping preview after compress (broken fonts or images).
- Emailing a 50 MB deck when compress was unticked.
- Cleaning MASTER instead of a copy.

## Accessibility check in practice

The check surfaces missing alt text and other issues it can detect. Alex still writes alt text at authoring time in Slide Deck Maker. Studio reports; it does not invent alt text for every photo. He fixes critical misses before the final send.

## Watermark policy

Draft external shares: light diagonal DRAFT. Final: no watermark. Legal holds: follow counsel instructions—sometimes a CONFIDENTIAL mark stays on every external copy. Alex never invents a legal mark without approval.

## FAQ

**Does Presentation Studio build slides from an outline?**
No. It finishes an existing presentation. Use Slide Deck Maker to author.

**Do all files stay on my device?**
`.pptx` processing stays in the browser. Other presentation formats are converted on FreeDailyPro servers first.

**Can I run only some steps?**
Yes—tick what you need; order remains fixed among the ones you select.

**Is compress the same as Compress PowerPoint?**
Studio includes a compress step in the finish sequence. Compress PowerPoint remains available as a single-purpose Professional tool.

**Will clean for sharing remove my charts?**
It targets sharing risks such as leftover notes and similar cleanup—not your intentional slide content. Always preview.

**What if the partner only accepts PDF?**
Finish in Studio, then PowerPoint to PDF for the delivery file.
