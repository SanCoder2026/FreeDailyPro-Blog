## Common mistakes

- Editing only the HTML copy until Markdown is abandoned and unmaintainable
- Forgetting that some CMS systems sanitize tags
- Pasting Markdown into an HTML field without conversion
- Ignoring heading hierarchy (skipping from h2 to h5)
- Leaving broken relative links
