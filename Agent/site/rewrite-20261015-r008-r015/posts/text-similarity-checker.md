## Common mistakes

- Treating any score tool as a courtroom verdict
- Comparing wrong file versions
- Ignoring quotes that should be cited rather than rewritten poorly
- Pasting only one paragraph when the match is elsewhere
- Using similarity tools to harass rather than to teach
- Forgetting that paraphrasing without citation can still be misconduct under school policy
