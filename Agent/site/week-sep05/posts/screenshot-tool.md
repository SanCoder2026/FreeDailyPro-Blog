FreeDailyPro's [Screenshot Tool](https://www.freedailypro.com/tool/screenshot-tool) captures, crops, rotates, and draws or highlights before copy or download.

## Capture with intent

Capture wide, crop tight. Leave enough UI to identify the app. Hide secrets. One highlight color. One arrow. Short text only when needed.

## Still vs motion

Use stills for one state. Use [Screen Recorder](https://www.freedailypro.com/tool/screen-recorder) for multi-step motion bugs. Match medium to problem.

## Work constraints

Locked-down PCs often block installs. Browser capture-and-mark tools reduce friction. OS policies can still block some captures; no web tool invents pixels it never received.

## Habit

Name screenshots by ticket ID. Clear pictures shorten support threads more than most documentation habits.
